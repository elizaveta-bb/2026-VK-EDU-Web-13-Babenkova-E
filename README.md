# AskBabenkova

Учебный проект сайта вопросов и ответов.
Домашнее задание №1 — статическая верстка на HTML, CSS и Bootstrap 5.3.8.

## Как открыть

Склонируйте репозиторий и откройте public/index.html в браузере.

На macOS из папки проекта:

    open public/index.html

Установка зависимостей и запуск сервера не требуются.
Стили Bootstrap и изображения хранятся локально.

## Страницы

| Файл | Содержание |
| --- | --- |
| public/base.html | Общий каркас страницы |
| public/index.html | Список вопросов |
| public/question.html | Вопрос, ответы и форма ответа |
| public/ask.html | Форма создания вопроса |
| public/login.html | Форма входа |
| public/signup.html | Форма регистрации |
| public/profile.html | Настройки профиля |

## Структура

- public/ — HTML-страницы.
- public/static/css/ — Bootstrap и собственные стили.
- public/static/js/ — папка для JavaScript.
- public/static/img/ — аватарки и favicon.

## Состояния интерфейса

- На главной показаны лайк, дизлайк и отсутствие оценки.
- На странице вопроса показаны выбранная и пустая отметки правильного ответа.
- В формах показаны примеры ошибок и подсказки.
- На странице профиля показана шапка авторизованного пользователя.
- На остальных страницах показаны ссылки входа и регистрации.

## Ограничения макета

Данные вписаны в HTML. Отправка форм, поиск, голосование
и переключение содержимого через пагинацию не реализованы.

Страница вопросов по тегу запланирована для ДЗ2.
