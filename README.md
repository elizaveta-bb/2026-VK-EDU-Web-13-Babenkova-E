# AskBabenkova

Учебный проект сайта вопросов и ответов.

- ДЗ1 — статическая верстка на HTML, CSS и Bootstrap 5.3.8.
- ДЗ2 — Django: обработка HTTP-запросов, маршрутизация,
  шаблоны и пагинация на данных-заглушках.

## ДЗ1 — статическая верстка

### Как открыть

Склонируйте репозиторий и откройте `public/index.html` в браузере.

На macOS из папки проекта:

```bash
open public/index.html
```

Для просмотра статической верстки установка зависимостей
и запуск сервера не требуются.
Стили Bootstrap и изображения хранятся локально.

### Страницы

| Файл | Содержание |
| --- | --- |
| public/base.html | Общий каркас страницы |
| public/index.html | Список вопросов |
| public/question.html | Вопрос, ответы и форма ответа |
| public/ask.html | Форма создания вопроса |
| public/login.html | Форма входа |
| public/signup.html | Форма регистрации |
| public/profile.html | Настройки профиля |

### Структура верстки

- `public/` — HTML-страницы.
- `public/static/css/` — Bootstrap и собственные стили.
- `public/static/js/` — папка для JavaScript.
- `public/static/img/` — аватарки и favicon.

### Состояния интерфейса

- На главной показаны лайк, дизлайк и отсутствие оценки.
- На странице вопроса показаны выбранная и пустая отметки правильного ответа.
- В формах показаны примеры ошибок и подсказки.
- На странице профиля показана шапка авторизованного пользователя.
- На остальных страницах показаны ссылки входа и регистрации.

### Ограничения статического макета

Данные вписаны в HTML. Отправка форм, поиск, голосование
и переключение содержимого через пагинацию не реализованы.

## ДЗ2 — Django

### Структура проекта

- `application/` — настройки проекта и корневые маршруты.
- `core/` — страницы входа, регистрации и профиля.
- `questions/` — страницы вопросов, данные-заглушки и функция пагинации.
- `templates/` — базовый шаблон и общие подшаблоны.
- `core/static/core/` — исходные стили и изображения.
- `static/` — каталог для собранной статики.
- `media/` — каталог для загруженных файлов.
- `manage.py` — управление Django-проектом.

### Настройка окружения

Все команды выполняются из корня репозитория,
где находится `manage.py`.

Перед первым запуском создайте `.env`:

```bash
cp .env.example .env
```

Если `.env` уже существует, повторно копировать файл не нужно.

В `.env` замените значение `DJANGO_SECRET_KEY` на свою длинную
случайную строку. Остальные значения из примера подходят
для локального запуска:

- `DJANGO_DEBUG=True`
- `DJANGO_ALLOWED_HOSTS=localhost,127.0.0.1`

Файл `.env` исключен из Git. Пример настроек находится
в `.env.example`.

### Локальный запуск

Требуется Python 3.13.

Создайте виртуальное окружение и установите зависимости:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

После настройки `.env` примените миграции и запустите сервер:

```bash
python manage.py migrate
python manage.py runserver
```

Откройте http://127.0.0.1:8000/.

Для остановки сервера нажмите `Ctrl+C`.

### Запуск через Docker Compose

Требуются Docker и Docker Compose.
На macOS перед запуском откройте Docker Desktop
и дождитесь запуска движка.

После настройки `.env` выполните:

```bash
docker compose up --build
```

Миграции применяются автоматически при запуске сервиса `web`.

Откройте http://127.0.0.1:8000/.

Порт `8000` контейнера проброшен на порт `8000` компьютера.
Код проекта подключен через volume, поэтому изменения файлов
доступны в контейнере без пересборки образа.

Для `media/` используется отдельный именованный volume
`media_data`, сохраняющий файлы при пересборке контейнера.

Для остановки нажмите `Ctrl+C`. Чтобы удалить остановленные
контейнеры и сеть проекта, сохранив volume с файлами:

```bash
docker compose down
```

### Пагинация

Списки вопросов и ответов выводятся по 10 элементов на странице.

Номер страницы передается параметром `page`, например:

- `/?page=2`
- `/hot/?page=2`
- `/tag/python/?page=2`
- `/question/35/?page=2`

Общая функция `paginate` находится в `questions/utils.py`.
При некорректном или выходящем за диапазон номере
возвращается первая страница.

Шаблон пагинатора: `templates/includes/pagination.html`.

### Ограничения ДЗ2

Вопросы, ответы и данные профиля являются заглушками.
Формы отображаются без сохранения данных.
Авторизация, загрузка файлов, поиск и голосование
на сервере пока не реализованы.
