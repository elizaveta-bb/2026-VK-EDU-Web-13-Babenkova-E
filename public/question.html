Как подключить Bootstrap к HTML-странице?

Делаю свой первый сайт вопросов и ответов. По заданию все стили должны храниться локально.

Я скачала Bootstrap и создала свой файл style.css. В каком порядке их подключать, чтобы мои стили могли изменять оформление Bootstrap?

Александр

Сначала подключи bootstrap.min.css, а следующей строкой — свой style.css. При одинаковой специфичности селекторов более позднее правило получает приоритет, если остальные условия каскада совпадают.

Оба файла подключаются через тег <link> внутри <head>.

Анна

Ещё проверь пути к файлам. Если HTML лежит в public, а стили — в public/static/css, путь в HTML будет начинаться с static/css/.

Если оформление не изменилось, сохрани CSS и обнови страницу в браузере.
